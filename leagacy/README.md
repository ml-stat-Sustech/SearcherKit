# WebAgent Monorepo

This repository currently hosts two related but independent components:

- `src/webagent/` – the original **WebAgent** multi-agent CLI framework (see `src/webagent/README.md`).
- `src/local_wiki/` – the local Wikipedia indexing & retrieval pipeline (see `src/local_wiki/README.md`).

Each sub-project ships with its own README covering setup, dependencies, and workflows. Choose the folder that matches what you need to work on.
